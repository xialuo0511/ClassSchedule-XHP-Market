# 星瀚课程表更新日志

## 1.2.7（2026-08-30）

- 所有底部弹窗现在都可通过系统返回键直接关闭。
- 调课方式立即切换，仅保留表单高度过渡，不再等待淡出。
- 周课表使用定位与人物图标区分地点和教师信息。
- 后台新版本提示改为更简短自然的文案。
- 修复深色模式下插件入口、列表、市场和详情图标没有圆角的问题。

## 1.2.6（2026-08-30）

- 课程详情使用定位信息块与教师信息卡，地点和教师更容易区分。
- 修复插件详情加载完成后弹窗下移及圆角阴影异常。
- 修复双列及三列滚动选择器向下滑动时可能误关闭弹窗的问题。
- 调课弹窗改用统一日期和节次滚轮，并增加高度过渡、课时数与课程冲突校验。

## 1.2.5（2026-08-30）

- 插件市场新增按学校名、插件名、说明、作者和标签的本地搜索。

## 1.2.4（2026-08-30）

- 修复跨多个版本升级时更新日志过长、内容无法完整查看的问题。
- 更新日志短内容保持自适应高度，超过 240dp 后可在卡片内独立滚动。
- 限制日志区域高度，避免“稍后”和“立即更新”按钮被推出屏幕。

## 1.2.3（2026-08-30）

- 历史更新日志区域提高到 280dp，并使用主题重点色突出各版本号。
- 下载进度升级为带图标、字节进度、百分比标签和圆角轨道的主题色卡片。
- 后台发现新版本时显示一次可操作提示，同一版本不再重复提醒。
- 设置页“发现 vX.X”徽标改为跟随当前主题颜色。

## 1.2.2（2026-08-29）

- 已是最新版本时提供默认收起的历史更新日志入口。
- 展开后按版本从新到旧展示发布时间和每个版本的更新内容。
- 展开与收起沿用更新弹窗的平滑高度过渡，并支持在固定区域内滚动查看。

## 1.2.1（2026-08-29）

- 更新安装包改为由 App 直接下载并显示实时进度，避免小米系统下载组件停在 0%。
- 下载完成后校验官方索引中的 SHA-256，再交给系统安装器确认安装。
- 修复更新日志中损坏占位字符显示为乱码的问题，并改用兼容性更好的纯文本排版。

## 1.2（2026-08-29）

- 启动 App 后会在后台静默检查新版本，发现更新时在设置页“检查更新”旁显示提示，不再主动弹窗打断使用。
- 重构考试与作业界面，支持将已完成事项恢复，并统一日期、时间与提醒选择体验。
- 完善上课提醒、每日课程摘要与桌面小组件设置，并修复 Android 16 滚动选择器兼容问题。
- 改进课程导入、同名课程多时段地点显示及学期开始前和结束后的课程阅览体验。

## 1.1（2026-08-28）

- 接入版本检查，并从官方 GitHub Release 下载更新。
