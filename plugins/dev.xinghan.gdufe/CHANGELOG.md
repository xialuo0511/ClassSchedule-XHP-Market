# 2.0.2

- 使用独立插件 ID `dev.xinghan.gdufe`，与通用强智插件明确区分。
- 点击插件后显示“插件更新信息”原生弹窗。
- 广财教务登录令牌按一次性会话处理，移除 `headless_action` 与“直接更新课表”。
- 更新课表时统一进入可见网页登录流程，登录成功后继续自动解析与提交。

# 2.0.1

- 修复广财强智教务会话未初始化时反复显示 `flag1=2` 的问题。
- 登录入口改为 `/jsxsd/`，由服务器先创建登录会话，再自动进入课表页。
- “重新登录”不再刷新课表接口，而是返回真正的登录入口。

# 2.0.0

- 将通用强智入口固定为广东财经大学教务系统，不再要求用户手动输入 URL。
- 登录完成后自动打开当前学期课表、解析课程并提交导入。
- 自动读取强智校历页面，生成学期开始日期与周数；读取失败时采用保守回退。
- 根据校区名、教学楼名称及楼栋代码识别广州或佛山（三水）校区。
- 按广财上课时间表写入两校区各 12 节完整节次时间。
- 保留对强智 `#kbtable`、多课程单元格、单双周、连续周与多地点课程的解析兼容。
