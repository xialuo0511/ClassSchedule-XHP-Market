# 广东财经大学课表自动导入插件

这是面向广东财经大学（GDUFE）强智教务系统的 XHP Protocol 3 插件，使用独立插件 ID `dev.xinghan.gdufe`。

## 使用方式

1. 在课程表 App 中安装 `dist/gdufe-course-import-2.1.0.xhp`。
2. 点击插件，先查看当前版本更新信息，再选择“打开插件”。
3. 在学校网页完成登录和验证码。校外或手机流量环境通常需要先连接学校 VPN。
4. 登录成功后，插件会自动进入当前学期课表页、读取校历、识别课程与校区，并向 App 提交导入确认。

广东财经大学教务登录令牌按一次性会话处理，因此不提供“直接更新课表”。每次更新都从可见网页登录入口开始，插件不读取或保存账号、密码。

宿主 App 的安全规则要求课程提交显示原生确认框；插件不会绕过该确认框。确认后，目标学期现有课程会被本次结果整体替换。

## 自动校区识别

插件优先依据课程地点中的校区名、教学楼名和楼栋代码识别：

- 佛山（三水）校区：厚德楼、励学楼、拓新楼、笃行楼、SJ1/SJ2/SJ3/SS1 等。
- 广州校区：第一教学楼、第三教学楼、经管实验楼、实验楼、综合楼、J1/B4/B5/S1/Z1 等。

识别成功后会提交完整的 12 节节次时间。若同时出现两个校区，按课程周次加权后的占比选择主要校区；占比相同或无法识别时，为避免写入错误时间，不覆盖 App 原有节次时间。

## 重要限制

课程表 App 当前每个学期只能保存一套全局节次时间，因此无法同时精确展示两个校区的不同上课时间。跨校区课表只能采用主要校区时间。

教务系统当前使用 HTTP 地址。HTTP 不加密登录内容，只应在可信校园网络或可信 VPN 环境中使用。

## 构建

Linux/macOS：

```sh
./build.sh ./dist/gdufe-course-import-2.1.0.xhp
```

Windows PowerShell：

```powershell
./build.ps1 -OutputPath ./dist/gdufe-course-import-2.1.0.xhp
```
