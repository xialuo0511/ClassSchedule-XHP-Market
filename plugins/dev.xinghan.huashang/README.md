# 广州华商学院课表导入插件

面向广州华商学院 `https://jwxt.gzhs.edu.cn/jsxsd/` 的 XHP Protocol 3 插件。学校使用强智教务，但课表解析和两校区作息由本插件单独维护，不会放宽通用强智插件的规则。

## 功能

- 登录后自动进入“学期理论课表”并解析课程。
- 通过表格逻辑网格处理 `rowspan/colspan`，同一跨行课程只解析一次。
- 同一课程、同一时间和地点的分周记录会合并周次，避免出现 180 门重复课程。
- 以详细字段中的 `周次(节次)` 为准，兼容 `[01-02-03-04节]` 与 `[09-10-11-12节]` 等四节连排写法；页面行标题仅作为兜底，节次严格限制为 1–13。
- 异常超过 80 条课程块或 50 门课程时停止提交。
- 优先读取教务页面已选择的“广州/肇庆校区时间模式”，其次根据地点识别校区；仍无法可靠识别、出现并列或跨校区时，要求用户手动选择。
- 按识别或选择的校区提交对应的完整 13 节时间。

## 两校区时间来源

以广州华商学院学生处发布的《2025-2026 学年校历以及两校区上课时间》为准：

https://xsc.gzhs.edu.cn/info/1046/7660.htm

广州校区第 1 节 `08:30–09:15`，肇庆校区第 1 节 `08:40–09:25`；第 9–11 节时间一致。

## 构建与测试

```powershell
node --check ./examples/plugin-huashang/main.js
node ./examples/plugin-huashang/tests/test.js
./examples/plugin-huashang/build.ps1
```

构建产物位于 `dist/huashang-course-import-1.0.2.xhp`。

## 当前验证边界

已验证公开登录页、官方两校区作息、JavaScript 语法、课表网格/周次合并算法和 XHP 包结构。由于测试环境没有华商学生账号，登录后的真实课表 DOM 仍需在学校账号下完成一次真机验收；插件会在数据量异常时停止导入，不会把异常的 180 门课程写入 App。
