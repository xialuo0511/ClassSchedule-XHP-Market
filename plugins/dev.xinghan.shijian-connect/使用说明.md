# 时笺联动：快速开始

1. 安装星瀚课程表 **1.5.0测试版**，在设置安装`shijian-connect-1.0.0.xhp`。
2. 电脑时笺开启“课程表联动 → 手机插件直连”，允许局域网连接。手机与电脑接入同一可信网络。
3. 插件点“连接电脑”，填电脑IPv4地址、端口和配对令牌。默认仅本次，需保存时主动勾选本机加密保存。
4. 点“选择学期并预览”，核对学期、课程、课次数；勾选要同步的学期，再点“确认并同步”并确认原生弹窗。
5. 网络失败请重试同一次提交。配对失效需重新配对，预览过期/桌面课表变化需重新预览。
6. “断开”清除活动连接，“删除配对”连同保存的地址和令牌一起删除。今日计划摘要需电脑另行授权，只读展示。

同步替换同名、同开始日学期的旧导入课次；个人任务与手工日程保留。**当前导出没有单次调课、停课及节假日覆盖，这些调整不会同步。**
