# 时笺联动 1.0.0

将星瀚课程表中由你选定的单个或全部学期同步到 Windows 时笺。需要 **星瀚课程表 1.5.0 或更高版本（Bridge API 4）**，旧版宿主不能安装本插件。

## 使用

1. 安装星瀚课程表 1.5.0 测试包，再在“设置 → 安装插件”选择 `shijian-connect-1.0.0.xhp`；也可从插件市场的“功能插件”分类安装。
2. 在 Windows 时笺“课程表联动 → 手机插件直连”开启服务并启用局域网；手机、电脑连接同一可信局域网。根据 Windows 提示允许该应用连接。
3. 打开“时笺联动 → 连接电脑”，在原生输入框填写电脑 IPv4 地址（例如 `http://192.168.1.20:19082`）和时笺显示的配对令牌。只检查 `/api/v1/health` 服务兼容性，令牌权限在预览/摘要请求时验证。
4. 默认“仅本次”；需下次使用时，主动勾选“在本机加密保存配对”。未勾选时，连接成功会移除以前的保存；退出插件、进入后台或页面重建会清除活动连接。已加密保存的配置可用“删除配对”清除；卸载插件也会删除。
5. 点击“选择学期并预览”，在宿主原生选择框选定单个或全部学期。预览会列出学期、课程数和课次数，可继续勾选需要提交的学期。
6. 核对后点击“确认并同步”，在原生确认框确认替换范围。成功会显示学期数、课次数；如果网络失败，点击“重试同一次提交”，沿用原 `commitId`。
7. 可选点击“读取摘要”：只有 Windows 用户勾选允许已配对设备读取今日计划摘要时才可用。该功能只读，不修改学习任务。

配对失效（401）需重新填写令牌；预览不存在/过期（404）或对应桌面课表变化（409）需重新预览并再次确认。请求过大（413）时改为单学期，待确认预览较多（429）时稍后再试。

## 同步范围

- 原样复用 `SemesterScheduleExporter` 的 v1 JSON：`classschedule-semester` 或 `classschedule-all-semesters`。保留节次、周规则、教师、教室、备注和提醒字段，不另造导出格式。
- 预览只校验与暂存，确认后才提交。时笺会原子替换同名、同开始日学期的旧导入课次；个人任务、手工日程和其他课表保留。重复提交与重新导入依赖时笺的幂等提交和稳定课次标识。
- **当前 v1 JSON 不含单次调课、停课和节假日覆盖，它们没有被同步。** 学习任务首版没有双向写入。
- Windows 服务关闭/重启后请重新检查连接；未明确获得提交结果时，先重试同一提交。服务重启使幂等结果缓存失效时，需重新预览；稳定课次标识仍防止重复建课。

## 凭据与能力

插件使用前台页面，并申请两项能力：

- **用户选择后只读导出学期课表**：仅导出你在原生选择框中选定的学期。
- **连接用户指定局域网时笺，可选本机加密配对**：由宿主连接你配对的电脑。

不申请导入课表、后台同步、无界面或教务登录能力。只在本地前台页运行，网页网络和站点存储关闭。

令牌仅在原生输入框与宿主内存中处理，使用原生 HTTP 的 `Authorization: Bearer …`；不进入 JavaScript、URL、日志、课表或导出文件。可选保存使用 Android Keystore 的 AES-GCM 加密，按插件隔离，位于不参与系统备份的目录。HTTP 仅用于可信局域网，不能提供传输加密；如部署支持有效证书的 HTTPS，可填写相应地址。

原生请求限定用户填写的局域网 IPv4 和 Connect v1 的四个接口；不接受 URL 查询参数、自定义认证头或跨地址跳转。没有读取教务账号、密码、Cookie 的接口。

## 构建与测试

```powershell
./plugins/dev.xinghan.shijian-connect/build.ps1
node --test plugins/dev.xinghan.shijian-connect/tests/workflow.test.js
```

默认输出 `dist/shijian-connect-1.0.0.xhp`，ZIP 根目录仅包含 `plugin.json`、`main.js`；构建会校验最低宿主版本、包体限制、内容读回和 SHA-256，重复构建可得到相同文件。

宿主测试位于 `plugin/PluginCompatibilityTest`、`plugin/connect/` 与 `plugin/PluginConnectInstrumentedTest`。跨端验收使用临时 SQLite 数据与真实 `ClassScheduleBridge`，不连接个人时笺数据库；Windows 的原有契约检查在 `tests/Shijian.IntegrationChecks`。
